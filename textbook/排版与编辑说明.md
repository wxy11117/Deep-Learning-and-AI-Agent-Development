# 修订版排版与编辑说明

本版依据用户提供的教材样张调整字体层级和版面。正文继续使用小四号宋体，段落按论证需要自然长短变化。内容、图示与项目沿用本书自己的体系。

| 内容 | 字体与字号 | 排版方式 |
|---|---|---|
| 封面主标题 | Noto Sans SC 900；58 / 38 pt | 厚重黑体，轻微倾斜，原创信号交织图形 |
| 作者扉页 | Noto Serif SC 600 书名字体；英文 Georgia；Great Vibes 28 pt 署名；楷体 12 pt 题辞 | 第 2 页，原创神经网络、注意力与 Agent 工作循环矢量图；不印页眉页码 |
| 章标题 | Noto Sans SC 700；23 pt | 章号与名称组合，主题色细线 |
| 节标题 | Noto Sans SC 700；13 pt | 依章配色，段前留白，跟随首段 |
| 正文 | SimSun 宋体；12 pt | 通常 1.7 倍行距，局部 1.55—1.65 倍；首行缩进两字 |
| 注记 | KaiTi 楷体；11.5 pt | 黑体“注”标签，适量独立留白 |
| 算例与推演 | 宋体正文、黑体标签 | 浅色底与左侧竖线，长推演允许跨页 |
| 数学公式 | KaTeX 专用字体；11.5 pt 基准 | 白底居中，按章编号，编号靠右 |
| 图注 | 宋体；10 pt | 按章编号，说明对象、单位与数据性质 |
| 表格 | 宋体；9.5 pt，粗黑体表头 | 浅色表头、细横线与适度留白 |
| 代码 | Consolas；8.7 pt，中文宋体后备 | 等宽排版，浅灰底，长行换行 |
| 页眉、页脚 | 宋体与西文衬线字体 | 章／节运行页眉、细线、分层页码 |

纸型为 A4。正文页上、右、下、左边距分别为 24、22、21、24 毫米。前置部分使用小写罗马页码，正文从第一篇开始使用阿拉伯数字；PDF 页标签与印刷页码同步。简明总目录展示三篇与 44 章主线，详细目录展开到全部节，包含点状引导线、右对齐页码和内部跳转。

封面与阅读说明之间加入独立作者扉页，署名依次为 Violet、Star、Sapphire。扉页顶部直接排书名，不加丛书名称或宣传语；作者下方为丘吉尔题辞。扉页不参与罗马页码计数，阅读说明仍从 i 开始。题辞出处与日期在 `author_page.json` 中记录；图示为自行绘制的矢量作品，保留可编辑生成脚本。

蓝、青绿、紫、莓红、暖橙用于区分章节与图表，正文保持深色以便连续阅读。封面的交织线条和点阵为独立绘制的矢量图，借鉴参考封面的部分仅限厚重标题字的风格。

此前的全书语气检查将反复出现的泛化否定、免责式提醒改为具体机制、实验条件、结果解释与后续操作。数据来源、模拟方式和离线回放在项目说明中直接交代。数学定义、算法前提和操作规则保留清楚的技术含义。具体修订见 `语气修订记录.json`。

本轮面向零基础的增补覆盖 44 章。多数例子融入自然段落，5 处采用浅色小例子框，6 处使用原创图解，7 个近年应用案例采用随章节变色的资料框。简单术语简短解释，核心抽象概念采用具体数字、图示与公式逐步连接；段落与案例长度随问题变化。

新增图解依次对应参数学习、张量形状、卷积计算、注意力汇总、RAG 与 Agent 工具循环。正文维持 12 pt 宋体，标题、说明和来源使用不同字重与字号。分页复核对少数章节局部调整行距、段间距与图宽，收回只有几行文字的章末尾页。

权威正文位于 `新版章节/01.md`—`44.md`。`assemble_revised.py` 负责组装，`build_book.mjs` 负责排版，`finish_layout.py` 负责页眉页码与定位。修改正文后应重新构建，直到目录页码与实际分页一致。
