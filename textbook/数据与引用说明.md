# 数据、引用与图表来源

编写与核验日期：2026-11-10。各章在对应概念附近列出原论文或官方文档链接。本说明集中记录配套项目的数据性质。

## 公开数据

共享单车项目使用 [UCI Bike Sharing 数据集](https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset) 中的 day.csv，共 731 天，来自 Capital Bikeshare 2011—2012 年记录。建议引用：Fanaee-T, H. (2013). Bike Sharing. UCI Machine Learning Repository. [DOI: 10.24432/C5W894](https://doi.org/10.24432/C5W894)。UCI 页面列示许可为 CC BY 4.0。本书重新构造滞后特征并按时间划分，未修改保存的原始压缩包。

原始压缩包 SHA-256：

数字识别项目使用 [scikit-learn load_digits](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_digits.html)，共 1797 个 8×8 样本。其来源为 [UCI Optical Recognition of Handwritten Digits](https://archive.ics.uci.edu/dataset/80/optical+recognition+of+handwritten+digits)。原数据作者为 E. Alpaydin 与 C. Kaynak。原始数据通过统计 32×32 位图中 4×4 小块的前景像素，生成 8×8、数值 0—16 的表示。

本书使用 load_digits 所含子集重新按样本分层划分为 1078/359/360，并在同一划分下比较模型。这里采用样本级划分；按书写者分组的评估方法见第 23 章。

## 模拟与虚构数据

传感器时序由固定随机生成器构造，包含平滑运动、噪声、尖峰与缺失。干净真值与噪声轨迹同时保留，便于逐项比较估计算法。

缺陷分割图像由程序合成灰度纹理与细线划痕，按固定生成机制独立构造训练、验证与测试样本。

检索语料是十二条作者编写的虚构设备说明；供电、报警、采样等参数与十五个问题配套设计，用于逐项检查检索机制。

NumPy、PyTorch 二维分类示例使用人工同心圆数据。迷你 Transformer 使用两条固定整数序列，只检查拟合、形状、梯度和因果约束，没有独立泛化评测。

## 图表与公式

结构图以 figures/structures.md 和 figures/agent_structures.md 中 Mermaid 文本为源文件，并导出 SVG 和 PNG。40 组数值图保存 300 DPI PNG 与矢量 PDF，19 组结构图保留可编辑文本。另有 6 组入门图解及 3 组综合案例图示，全书合计 68 组正文图示。

公式说明、手算样例、比较分析和项目叙述为本书原创编写。原方法的归属见正文链接，配套实验数字对应资料包中保存的运行结果。

离线阅读版内嵌图片、KaTeX CSS 与公式字体，不需要联网加载阅读资源。构建使用 KaTeX 0.16.22、Mermaid 10.9.3、Marked 17.0.5 与 Playwright 1.62.1。

## 新增 Agent 案例

知识库项目采用作者编写的六条虚构教学设备说明 K01—K06，含 1.0 与 2.0 版本，不属于真实产品。原文写在 agent_projects/knowledge.py。字符二元组计数余弦检索用于最小可复现实现；它与原文档检索项目的 TF-IDF 基线不同。

数据分析项目使用 agent_projects/data/orders.csv 的十三行模拟订单。金额、地区、月份、重复记录和异常值均为教学构造。清洗后保留十行，包括一笔退款。第 41 章的地区聚合图来自程序对这些模拟记录的实际计算。

工单项目使用临时 SQLite 数据库中的模拟工单 T001。批准由独立测试夹具提供，实际测试了检查点恢复、版本绑定、事务回滚和幂等处理；没有接入用户的真实工单服务。

三个项目的默认模型回复均为离线回放输入，程序执行和 MCP 子进程通信为真实本地运行。保存结果记录工程行为；新增 DeepSeek 真实模型实验单独保存在 case_study/lungsight，方法与结果见第 38.10—38.11 节。书中独立步成功率、重试概率、Wilson 区间、上下文预算和并行耗时图分别标明数学假设或人工样例。

## 字体来源与输出

参考用户提供的纸质教材照片，PDF 正文使用 SimSun 宋体、小四号 12 pt，注记采用 KaiTi 楷体。章与节标题使用 Noto Sans SC 700，封面标题使用 Noto Sans SC 900，数学使用 KaTeX 字体，代码采用等宽字体。PDF 嵌入所需字形；资料包仅附带获开放许可的 Noto 字体子集。

跨设备 HTML 正文和数值图使用 Noto Serif SC 的常规字重作为宋体风格后备；随包提供从 NotoSerifSC-VF.ttf 的 wght=400 实例制作的字形子集。该字体采用 SIL Open Font License 1.1，许可见 vendor/fonts/LICENSE.txt，来源说明见 vendor/fonts/README.md。数值图中的西文及数学符号必要时由 DejaVu Serif 补齐。

封面信号交织图由 `create_cover_art.py` 原创生成。参考封面仅提供厚重标题字的字体风格启发。Noto Sans SC 子集由 `prepare_style_fonts.py` 生成，许可及来源见 `vendor/fonts/README.md`。

Agent 篇引用优先指向原论文、官方协议和官方文档。MCP 代码实验固定 2025-11-25 版本，Anthropic 适配器固定 2023-06-01 请求版本，用于解释与复现。升级接口时应按目标服务的官方文档核对。全书末尾另有三节按问题组织的延伸阅读索引。
